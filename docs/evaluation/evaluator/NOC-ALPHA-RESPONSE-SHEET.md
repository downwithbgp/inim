# NOC alpha evaluation — response sheet

Manual response sheet. Print it or copy it per session; do not submit
it automatically. The facilitator keeps the completed copy; nothing is
stored by the application.

## Session header

| Field | Value |
|---|---|
| Anonymous evaluator code | |
| Date | |
| Role category | |
| Approximate years of network-operations experience | |
| BGP familiarity | occasional / regular / expert |
| Prior RouteViews/RIS use | never / occasional / regular |

The evaluator code is a short random label (e.g. `E-7K2`). No real name
and no employer are required. If the facilitator needs identity for
follow-up, that mapping is kept outside this repository.
