# Session-notes template

Facilitator notes per evaluation session. Distinguish the three record
kinds and never merge them:

- **Observation** — what the facilitator saw the evaluator do
- **Quote** — an evaluator statement, recorded verbatim where practical
- **Inference** — the facilitator's interpretation

Do not record private employer or customer data. Do not record real
names. Sanitize before committing anything.

## Evidence-trust comments

Record evaluator statements about evidence references, archive
identities, and whether they believed the shown evidence.

## Requested features

Record feature requests verbatim (Quote) with the context (Observation).

## Facilitator observations

Free-form observations, each labeled Observation / Quote / Inference.

Example of the format (neutral, not real feedback):

- Observation: evaluator opened the second scenario URL directly
  without returning to the dashboard.
- Quote: "I expected the timeline to show the whole day."
- Inference: the timeline window scope was not obvious from the page
  header alone.
