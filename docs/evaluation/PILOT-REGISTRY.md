## Rules

- This registry is manually maintained by the project owner or
  facilitator.
- Do not pre-populate fake evaluator entries.
- Do not treat Agent validation as external evaluation.
- Do not treat the project owner's own review as an external evaluation
  unless the project owner explicitly decides to record it as such.
- The internal procedural dry run
  (`docs/audits/2026-08-evaluation-procedural-dry-run.md`) is
  procedural verification only and is never recorded here as an
  external session.
- Personal data: real names are not recorded by default. If follow-up
  requires identity, the facilitator maintains the mapping outside this
  repository and records only the evaluator code here.
